# Python fail-open authentication-secret detector

Added a bounded Python SAST detector for authentication guards that implicitly disable Bearer authentication when a required server token is missing. The candidate is source-backed by NewsDOM's reviewed protected fail-closed remediation, maps the weakness to CWE-306 and OWASP A07:2025, and includes production-scanner positive/fixed-negative regression evidence.

Review hardening rejects `Bearer` evidence found only in comments, log strings, a later sibling/outer class, or an optional-token flow nested inside a helper function or class. It still detects vulnerable outer authentication guards that contain nested declarations before the real guard logic by binding token, missing-secret return, and Bearer evidence to the outer function-body indentation. Comment-only lines are ignored when determining that indentation, including Python-valid comments whose physical indentation differs from the first executable suite statement. Public taxonomy metadata stays single-sourced in the parsed rule message, and the finding is classified as an authentication/authorization control issue with fail-closed operator guidance instead of hardcoded-secret rotation advice.
