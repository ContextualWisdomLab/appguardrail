## 2026-07-24 - Empty States and Error States Provide Helpful Guidance
**Learning:** Raw text messages without icons or formatting in empty states (like the initial "Connect" message) or error states (like API key failures) fail to provide clear, actionable guidance or reassure the user. A well-designed empty state with an icon, clear header, and secondary text significantly improves perceived usability.
**Action:** Always implement empty states with an icon, header, and helpful description (`.empty` pattern) instead of plain text or raw errors. Include loading states on buttons (e.g., `Connecting...` + `disabled`) to prevent double-clicks and provide immediate feedback during async operations.
