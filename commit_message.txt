🛡️ Sentinel: [CRITICAL] Fix DOM XSS in dashboard console

🚨 심각도: CRITICAL
💡 취약점: `console.html`의 템플릿 보간에서 사용자 입력값(`s.id`, `s.total`, `n`, `l`)이 이스케이프되지 않고 DOM의 `innerHTML`에 직접 삽입되는 DOM XSS(Cross-Site Scripting) 취약점이 발견되었습니다.
🎯 영향: 공격자가 악성 스크립트나 이미지 이벤트 핸들러(예: `<img onerror=alert()>`, `<script>`)를 포함한 API 응답을 변조하거나 주입할 경우, 대시보드 사용자의 브라우저에서 임의의 코드가 실행될 수 있습니다.
🔧 해결 방법:
- `console.html`에서 취약한 템플릿 보간에 기존 제공되는 `esc()` 새니타이저 함수를 적용했습니다.
- `tests/test_console_xss_contract.py`의 브라우저 기반 XSS 테스트를 Playwright 같은 외부 패키지 종속성 없이, `urllib.request`를 사용해 HTML 문자열 내의 주입된 이벤트 핸들러나 스크립트 존재 여부를 직접 파싱하여 점검하도록 수정했습니다.
✅ 검증: 회귀 테스트에서 `<img onerror=...>` 및 `<script>` 페이로드를 포함한 API 응답을 반환할 때 테스트가 실패하지 않음을 확인했습니다.
