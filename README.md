# VibeSec
Security guardrails for vibe-coded apps.

VibeSec helps builders using Cursor, Claude Code, Lovable, Replit, Bolt,
Supabase, Firebase, Vercel, and Netlify find and fix security issues
introduced during AI-assisted development.

It provides:
- Security rules for AI coding assistants
- Checklists for common vibe-coded stacks
- Lightweight scans for secrets, auth, authorization, and misconfigurations
- Fix prompts that help AI agents patch issues safely
- Founder-friendly security review templates
